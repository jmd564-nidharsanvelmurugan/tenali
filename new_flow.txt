# Updated Workflow: AI Proposal Generator with Direct User Prompt & Sales Questionnaire

## 📋 Overview of Changes

**New Flow:**
1. User uploads a **Sales Call Questionnaire** (DOCX file)
2. User provides a **Direct Prompt** describing their needs
3. Click **Generate** → API call to `/proposal/generate-proposal`
4. Backend retrieves the uploaded questionnaire and user prompt
5. Passes both to `ggg()` function for proposal generation
6. Returns generated proposal following the same process as before

# Instead of fetching Q&A, fetch the user prompt
def get_user_prompt(db: Session, conversation_id: UUID):
    """Retrieve the user prompt from the conversation"""
    prompt_message = db.query(Message).filter(
        Message.conversation_id == conversation_id,
        Message.message_type == "user_prompt",  # New field
        Message.role == "user"
    ).first()
    return prompt_message.content if prompt_message else ""

### **Step 5: Call ggg() Function**

The `ggg()` function replaces the previous Q&A processing and section generation.

#### **Function Signature:**
```python
async def ggg(user_prompt: str, sales_qa_text: str) -> str:
    """
    Generate proposal content using user prompt and sales questionnaire
    
    Input:
    - user_prompt: The user's direct prompt/requirements
    - sales_qa_text: Extracted text from the sales call questionnaire
    
    Output:
    - Complete generated proposal content (markdown format)
    """
```

#### **What ggg() Does:**

**5.1 Create Enhanced Prompt for LLM:**
```python
enhanced_prompt = f"""
USER REQUIREMENTS:
{user_prompt}

SALES CALL Q&A:
{sales_qa_text}

Based on the user requirements and sales call information above, generate a comprehensive proposal.
The proposal should include:
1. Executive Summary
2. Understanding of Client Needs
3. Proposed Solution
4. Implementation Approach
5. Timeline
6. Commercials
7. Next Steps

Use the sales call Q&A to personalize the proposal with specific details about the client's situation.
"""

# This enhanced prompt is sent to ggg() for processing
```

**5.2 RAG - Find Matching Proposal Templates:**
```python
# Use the combined input to find matching templates
user_input = f"{user_prompt}\n\n{sales_qa_text}"
proposal_metadata = db.query(ProposalMetadata).all()
top_proposals = get_n_matching_proposals(user_input, proposal_metadata)
# Returns: 5 best matching templates
```

**5.3 Load Template Content:**
```python
proposal_content = get_proposal_content(top_proposals)
# Returns: Content from the 5 matching templates
```

**5.4 Generate Proposal Sections (Parallel LLM):**
```python
sections = ['ExecutiveSummary', 'Understanding', 'Solution', 'Approach', 
            'Timeline', 'Commercials', 'NextSteps']

tasks = []
for section in sections:
    section_prompt = f"""
Generate the {section} section of the proposal.

User Requirements:
{user_prompt}

Sales Call Q&A:
{sales_qa_text}

Reference Content from Similar Proposals:
{relevant_template_content}

Create a tailored {section} section that addresses the specific needs mentioned.
"""
    tasks.append(fetch_chat_completion(section_prompt, system_prompt, docs_prompt, conversation_id))

results = await asyncio.gather(*tasks)
```

**5.5 Combine Sections:**
```python
combined_proposal = "\n\n".join([result["choices"][0]["message"]["content"] for result in results])
return combined_proposal
```

## 🔄 Comparison: Old vs New Flow

| Aspect | **Old Flow** | **New Flow** |
|--------|-------------|--------------|
| **Input Source** | Q&A from conversation messages | User Prompt + Sales Q&A |
| **Question Retrieval** | Fetches all Q&A pairs | Fetches only the user prompt message |
| **Sales Q&A** | Optional, uploaded separately | **Required**, uploaded before generation |
| **Input to ggg()** | N/A (no separate function) | **ggg(user_prompt, sales_qa_text)** |
| **Proposal Generation** | Based on Q&A answers | Based on user prompt and sales Q&A |
| **Sections** | 8 sections (BusinessContext, Understanding, etc.) | 7 sections (ExecutiveSummary, Understanding, Solution, etc.) |
| **User Experience** | Step-by-step Q&A | Single prompt + upload |
| **Time to Generate** | ~12-18 seconds | ~10-15 seconds (fewer sections) |

## ✅ Summary of Changes

1. **Removed**: Step-by-step Q&A flow
2. **Added**: Direct user prompt input
3. **Added**: Mandatory sales call questionnaire upload
4. **Added**: `ggg()` function that takes (user_prompt, sales_qa_text)
5. **Simplified**: From 8 sections to 7 sections
6. **Streamlined**: Single API call after prompt + upload
7. **Preserved**: RAG matching, template loading, parallel LLM calls, storage, indexing

The new flow is **faster, simpler, and more focused** - users provide their requirements once (via prompt) and the detailed context (via sales Q&A), and the system generates a comprehensive proposal in one go!
