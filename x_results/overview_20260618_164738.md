# Overview

PURE Financial Advisors’ current reporting environment spans multiple internal teams, primarily data, technology, and marketing, all of which contribute to pipeline and customer acquisition reporting. The firm operates a connected ecosystem built around Salesforce for CRM, Tamarac for portfolio management, and Azure-based data storage and processing. Data is housed across Salesforce, Tamarac, Azure Blob Storage, and QuickBooks, forming the core sources for financial and client activity data.

Reporting today is delivered through a Power BI suite that draws from these systems, supported by Microsoft Fabric and Azure Synapse as the underlying cloud and data platform infrastructure. While manual processes are not specified, integration between systems—particularly the ingestion of QuickBooks data—remains an active area of focus to ensure consistency and completeness in reporting. The current setup provides a structured foundation for data management and analytics across PURE’s operational and marketing functions.
