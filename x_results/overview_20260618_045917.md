# Overview

Pure Financial Advisors’ data, technology, and marketing teams collectively manage the firm’s pipeline and customer acquisition reporting processes. The current environment operates across several interconnected systems, including Salesforce for CRM, Tamarac for portfolio management, Azure Blob Storage for data hosting, Microsoft Fabric and Azure Synapse for data processing, and Power BI for analytics and visualization. QuickBooks is also part of the ecosystem and is planned for integration to support financial data alignment.

Reporting today is delivered through a Power BI suite that draws from multiple data sources—Salesforce, Tamarac, Azure Blob Storage, and QuickBooks. These sources form the foundation of Pure’s data landscape, supported by Microsoft Fabric and Azure Synapse as the core cloud and data platform infrastructure. While manual processes are not specified, integration challenges currently center on connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting.
