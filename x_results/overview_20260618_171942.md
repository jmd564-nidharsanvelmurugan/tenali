# Overview

PURE Financial Advisors’ current reporting environment spans multiple data, technology, and marketing teams responsible for managing pipeline and customer acquisition reporting. The firm operates on a connected data ecosystem built around Salesforce and Tamarac for client and portfolio management, supported by Azure Blob Storage, Microsoft Fabric, and Azure Synapse for data hosting and processing. Power BI serves as the primary reporting and analytics tool, providing visibility into existing pipeline metrics and performance dashboards.

Core data sources include Salesforce, Tamarac, Azure Blob Storage, and QuickBooks, with the latter identified for upcoming integration. The infrastructure is cloud-based, leveraging Microsoft Fabric and Azure Synapse to support data ingestion and transformation. While manual processes are not specified, integration challenges currently center on connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting.
