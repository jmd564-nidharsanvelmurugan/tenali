# Overview

PURE Financial Advisors’ current reporting environment spans multiple internal teams, primarily the data, technology, and marketing functions responsible for managing pipeline and customer acquisition reporting. These teams operate across a connected ecosystem of platforms including Salesforce, Tamarac, Azure Blob Storage, Microsoft Fabric, Azure Synapse, Power BI, and QuickBooks (pending integration).  

The firm’s existing analytics capability is centered on a Power BI reporting suite that draws from several core data sources—Salesforce, Tamarac, Azure Blob Storage, and QuickBooks. Underpinning these systems is a cloud infrastructure built on Microsoft Fabric and Azure Synapse, supporting data storage and transformation activities.  

While manual processes are not specified, current integration challenges include connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting. This environment provides the foundation for PURE’s operational and marketing data flows, enabling cross‑team collaboration through shared data assets and reporting tools.
