# Overview

Pure Financial Advisors’ current reporting environment spans multiple internal teams, primarily data, technology, and marketing, all of which contribute to pipeline and customer acquisition reporting. The firm operates on a connected data ecosystem built around Salesforce and Tamarac for client and portfolio management, Azure Blob Storage for data hosting, and Microsoft Fabric and Azure Synapse for data processing and analytics. Power BI serves as the central reporting suite, providing visual insights across these systems.

Data sources currently include Salesforce, Tamarac, Azure Blob Storage, and QuickBooks, with the latter identified for upcoming integration. The existing infrastructure is cloud‑based, leveraging Microsoft Fabric and Azure Synapse to support data ingestion and transformation. While manual processes are not specified, integration challenges exist around connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting.
