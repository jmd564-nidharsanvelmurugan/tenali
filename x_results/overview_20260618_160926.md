# Overview

Pure Financial Advisors’ current reporting environment spans multiple internal teams, primarily data, technology, and marketing, all of which contribute to pipeline and customer acquisition reporting. The firm operates on a connected technology stack that includes Salesforce for CRM, Tamarac for portfolio management, Azure Blob Storage for data hosting, Microsoft Fabric and Azure Synapse for data processing, and Power BI for analytics and visualization. QuickBooks is also part of the ecosystem and is planned for integration to support financial data alignment.

The existing reporting capability is centered around a Power BI suite that draws from several core data sources—Salesforce, Tamarac, Azure Blob Storage, and QuickBooks. These systems collectively support the firm’s operational and financial data needs within a Microsoft-based cloud infrastructure. While manual processes are not specified, integration challenges currently focus on connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting.
