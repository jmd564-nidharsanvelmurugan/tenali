# Approach

This engagement with VONQ is designed to deliver a comprehensive, investor-grade exit reporting suite that supports the company’s near-term sale process and equips senior leadership, advisors, and potential acquirers with transparent, reliable insights. Leveraging a structured yet pragmatic methodology, our approach is anchored in a focused Discovery & Design phase, producing all essential artefacts to enable a rapid transition into implementation. The methodology emphasises deep stakeholder engagement, data-driven analysis, and clear alignment with transaction objectives.

Our consulting team will collaborate closely with VONQ stakeholders to define equity narratives, prioritise key performance indicators (KPIs), assess data feasibility, and conceptualise the data model. Deliverables—including dashboard mock-ups, data infrastructure/tooling recommendations, and a detailed implementation roadmap—will be informed by current-state assessment and workshop feedback. All work will leverage the existing Qlik Warehouse platform, integrating data from Finance, CRM, and ERP systems, with additional sources considered as feasible and agreed.

**Phase 1: Discovery & Design, Duration: 4 weeks, Timeline: 29 June – 24 July 2026**  
**Summary:** Define and design the future-state exit reporting suite, equity narratives, KPIs, dashboards, and supporting data model to underpin the upcoming M&A process.

**Activities:**  
- Conduct stakeholder workshops to define equity narratives, establish a “Metrics That Matter” KPI framework, and prioritise key use cases.  
- Assess current-state data sources (Finance, CRM, ERP, legacy) to identify gaps, ingestion needs, and data refresh requirements for transaction reporting.  
- Develop conceptual data model and review compatibility with the Qlik Warehouse, evaluating extensibility to additional sources.  
- Produce static dashboard mock-ups illustrating target KPIs, data visualisations, and navigational layouts for exit reporting.  
- Evaluate current data infrastructure and reporting tools, providing clear, actionable recommendations (including pros and cons) to support scalability and investor needs.  
- Create an implementation roadmap detailing prioritised use cases, proposed sequence, key dependencies, risks, and milestones to guide Phase 2 delivery.  

---

In summary, this phased approach ensures that VONQ receives a complete set of investor-ready design artefacts to immediately inform implementation. By facilitating deep engagement with stakeholders, grounding recommendations in data-driven assessment, and mapping a clear path to Phase 2, we will equip VONQ with both the insight and structure needed to maximise transaction value and sustain future data-driven growth.
