# Overview

PURE Financial Advisors’ data, technology, and marketing teams collectively manage the firm’s pipeline and customer acquisition reporting processes. These functions operate across a connected ecosystem of platforms including Salesforce, Tamarac, Azure Blob Storage, Microsoft Fabric, Azure Synapse, Power BI, and QuickBooks (planned for integration). The existing reporting environment is centered on a Power BI suite that draws from multiple data sources to support business performance tracking and operational insights.

Core data assets reside in Salesforce and Tamarac for client and pipeline information, Azure Blob Storage for structured data management, and QuickBooks for financial data. The firm’s cloud infrastructure is built on Microsoft Fabric and Azure Synapse, providing the foundation for data storage and analytics. Current integration efforts focus on connecting QuickBooks and ensuring data quality to support accurate customer acquisition cost reporting. No manual processes or data governance policies are specified in the current documentation.
