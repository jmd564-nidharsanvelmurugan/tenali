# Deliverables

Throughout the engagement with VONQ, the following key deliverables and artifacts will be provided to ensure a comprehensive and actionable outcome aligned with the project objectives:

1. **Equity Narratives Definition**
   - Clear articulation of the business’s equity stories to underpin M&A sale positioning.
   - Documentation of narrative themes supported by data-driven rationale.
   - Delivered as a structured report and presented in stakeholder workshops.

2. **"Metrics that Matter" KPI Framework**
   - Prioritised inventory of commercial, financial, and operational KPIs required for investor reporting.
   - KPI definitions include calculation logic, data source mapping, and periodicity requirements.
   - Provided as a spreadsheet and supporting documentation for immediate use and ongoing updates.

3. **Dashboard Mock-ups**
   - Static visual mock-ups illustrating proposed dashboard layouts, navigation, and key metrics.
   - Wireframes covering essential views aligned to equity narratives.
   - Delivered in PDF and image formats for review, feedback, and workshop session walkthroughs.

4. **Data Feasibility Assessment**
   - Evaluation of available data across Finance, CRM, ERP, and legacy sources covering a minimum three-year trending requirement.
   - Identification and playback of current-state data gaps, integration readiness, and completeness by source system.
   - Delivered as a detailed findings report with recommendations for remediation priorities.

5. **Conceptual Data Model Design**
   - High-level architecture of the data model, built around Qlik Warehouse as the core reporting foundation.
   - Entity relationships, data flows, and key attribute documentation to support dashboard and KPI requirements.
   - Provided as a diagrammatic model with supporting technical notes, delivered in PowerPoint and PDF formats.

6. **Data Infrastructure and Tooling Recommendations**
   - Assessment of current and alternative reporting tools, platform options, and integration approaches.
   - Summary of pros, cons, and trade-offs for each tooling/infrastructure recommendation in context of scalability and exit-readiness.
   - Delivered as a comparative analysis matrix and executive summary document.

7. **Implementation Roadmap for Phase 2**
   - Phased plan outlining sequencing of key implementation activities, dependencies, risks, and milestones.
   - Clearly defined ownership, timelines, and critical paths to guide the next phase.
   - Delivered as an implementation plan document and Gantt chart, with risks and assumptions logged for reference.

Each deliverable will be iteratively reviewed with VONQ's leadership and technical teams to ensure alignment with business goals and to incorporate feedback promptly. This structured approach guarantees transparency, accountability, and measurable value throughout the engagement lifecycle.
