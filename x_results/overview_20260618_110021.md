# Overview

PURE Financial Advisors’ current reporting environment spans multiple internal teams, primarily data, technology, and marketing, all of which contribute to pipeline and customer acquisition reporting. The firm operates a connected ecosystem built around Salesforce and Tamarac for client and pipeline management, Azure Blob Storage for data hosting, and Microsoft Fabric and Azure Synapse as the core data platforms. Power BI serves as the primary reporting and analytics tool, supporting existing dashboards and performance tracking across these systems.

Data sources currently include Salesforce, Tamarac, Azure Blob Storage, and QuickBooks, with the latter identified for upcoming integration. The infrastructure is cloud‑based, leveraging Microsoft Fabric and Synapse for data processing and storage. While manual processes are not specified, integration challenges exist around connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting. Overall, PURE’s environment reflects a multi‑system data landscape anchored in Microsoft technologies and designed to support cross‑functional reporting needs.
