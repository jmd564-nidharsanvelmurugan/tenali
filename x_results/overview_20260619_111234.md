# Overview

PURE Financial Advisors’ data, technology, and marketing teams collectively manage the firm’s pipeline and customer acquisition reporting processes. These functions rely on a connected ecosystem of platforms including Salesforce for CRM, Tamarac for portfolio management, Azure Blob Storage for data hosting, Microsoft Fabric and Azure Synapse for data processing, and Power BI for analytics and visualization. QuickBooks is also part of the financial data landscape and is planned for integration into the broader reporting environment.

The current reporting suite is built in Power BI, drawing from multiple data sources—Salesforce, Tamarac, Azure Blob Storage, and QuickBooks—to support business performance tracking. The underlying infrastructure is anchored in Microsoft Fabric and Azure Synapse, providing a cloud-based foundation for data storage and transformation. While manual processes are not specified, existing integration challenges center on connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting.
