# Overview

PURE Financial Advisors’ current reporting environment spans multiple internal teams, primarily data, technology, and marketing, all contributing to pipeline and customer acquisition reporting. The firm’s operations are supported by a connected ecosystem of platforms including Salesforce, Tamarac, Azure Blob Storage, Microsoft Fabric, Azure Synapse, Power BI, and QuickBooks (pending integration). These systems collectively manage client, financial, and operational data across the organization.

Power BI serves as the primary reporting and analytics tool, drawing from several core data sources—Salesforce, Tamarac, Azure Blob Storage, and QuickBooks. The data infrastructure is built on Microsoft Fabric and Azure Synapse, providing the foundation for data storage and transformation. While manual processes are not specified, integration challenges currently center on connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting.
