# Overview

Poekmon’s reporting environment is supported by multiple internal teams across data, technology, and marketing, each contributing to the creation and maintenance of sales pipeline and customer acquisition reports. The company’s data ecosystem integrates several core systems: Salesforce and Tamarac for client and portfolio management, Azure Blob Storage for data storage, and Microsoft Fabric and Azure Synapse for data processing and analytics. Power BI serves as the primary reporting and visualization tool used by business and leadership teams.

The infrastructure is fully cloud-based, with Microsoft Fabric and Azure Synapse forming the backbone of Poekmon’s data processing environment. Data currently flows from Salesforce, Tamarac, and Azure Blob Storage, with QuickBooks planned for integration to expand financial data coverage. While the existing setup supports regular reporting, some processes still rely on manual coordination between teams to align data inputs and maintain report accuracy. Integration between systems—particularly the connection of QuickBooks for cost data—remains an area of active management within the current operations.
