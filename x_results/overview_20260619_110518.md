# Overview

Pure Financial Advisors’ current reporting environment spans multiple internal teams, primarily data, technology, and marketing, all of which contribute to pipeline and customer acquisition reporting. The firm operates a connected ecosystem built around Salesforce and Tamarac for client and asset management data, supported by Azure Blob Storage for data hosting and Microsoft Fabric and Azure Synapse for data processing and analytics. Power BI serves as the primary reporting and visualization tool, providing leadership and operational teams with access to existing performance dashboards.

Core data sources include Salesforce, Tamarac, Azure Blob Storage, and QuickBooks, with the latter identified for upcoming integration. The environment is cloud-based, leveraging Microsoft Fabric and Azure Synapse as the foundational data platforms. While manual processes are not specified, integration challenges currently center on connecting and ingesting data from QuickBooks and ensuring data quality for accurate customer acquisition cost reporting.
