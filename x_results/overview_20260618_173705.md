# Overview

PURE Financial Advisors’ current reporting environment spans multiple internal teams, primarily the data, technology, and marketing functions responsible for managing pipeline and customer acquisition reporting. These teams rely on a suite of interconnected systems, including Salesforce for CRM data, Tamarac for portfolio management, Azure Blob Storage for data hosting, Microsoft Fabric and Azure Synapse for data processing, and Power BI for analytics and visualization. QuickBooks is also part of the ecosystem and is planned for integration to support financial data alignment.

The firm’s reporting capabilities are centered around a Power BI suite that draws from several key data sources—Salesforce, Tamarac, Azure Blob Storage, and QuickBooks. The underlying infrastructure is built on Microsoft Fabric and Azure Synapse, providing a cloud-based foundation for data storage and transformation. While manual processes are not specified, integration challenges currently exist around connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting.
