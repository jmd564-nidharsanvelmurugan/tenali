# Overview

PURE Financial Advisors’ current reporting environment spans multiple internal teams, primarily data, technology, and marketing, all of which contribute to pipeline and customer acquisition reporting. The firm operates on a connected data ecosystem built around Salesforce and Tamarac for client and portfolio management, Azure Blob Storage for data hosting, and Microsoft Fabric and Azure Synapse as the core data platforms. Power BI serves as the primary reporting and analytics tool, supporting existing dashboards and performance tracking.

Data sources currently include Salesforce, Tamarac, Azure Blob Storage, and QuickBooks, with the latter pending integration into the broader data environment. The infrastructure is cloud‑based, leveraging Microsoft Fabric and Azure Synapse for data processing and storage. While manual processes are not specified, integration challenges exist around connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting.
