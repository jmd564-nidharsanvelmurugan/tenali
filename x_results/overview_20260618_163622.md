The firm’s operations rely on a connected ecosystem of platforms including Salesforce for CRM, Tamarac for portfolio management, Azure Blob Storage for data hosting, Microsoft Fabric and Azure Synapse for data processing, and Power BI for analytics and visualization. QuickBooks is also part of the financial data landscape and is planned for integration into the broader reporting framework.

The existing reporting suite is built in Power BI, drawing from several core data sources—Salesforce, Tamarac, Azure Blob Storage, and QuickBooks. These systems collectively support the firm’s data and reporting workflows, though integration between them is still evolving. The cloud infrastructure is anchored in Microsoft Fabric and Azure Synapse, providing the foundation for data storage and transformation. While manual processes are not specified, current operations include data ingestion and reporting activities that depend on these established platforms.
