# Deliverables

Throughout the engagement with VONQ, the following key deliverables and artifacts will be provided to ensure a comprehensive and actionable outcome aligned with the project objectives:

1. **Equity Narratives Definition**
   - Summary document defining the key equity narratives to be communicated in the exit process.
   - Capture of relevant business value drivers, priorities, and supporting storylines.
   - Alignment with investor expectations and transaction objectives.
   - Delivered as a presentation and supporting documentation following initial stakeholder workshops (Week 1).

2. **Metrics That Matter KPI Framework**
   - A prioritised framework of essential KPIs for commercial, financial, and operational performance.
   - Clear definitions, calculation logic, source mapping, and rationale for each KPI.
   - Highlighting of metrics aligned to the equity narrative.
   - Delivered as a structured matrix and descriptive reference guide (Week 2).

3. **Dashboard Mock-ups**
   - Static wireframes illustrating the proposed dashboards, including layout, key views, metrics, and navigation structure.
   - Representation of how investor-grade insights will be presented.
   - Design documented in both annotated mock-ups and an accompanying explanatory pack.
   - Delivered as PDF and/or image files with embedded documentation (Week 3).

4. **Data Feasibility Assessment**
   - Assessment of the current-state data landscape, identifying available, missing, or incomplete data sets.
   - Playback of findings regarding system integrations, data access, and quality gaps.
   - Recommendations for remediation and interim solutions where required.
   - Delivered as a summary report and data gap analysis (Week 2).

5. **Conceptual Data Model Design**
   - High-level design of data architecture to support the exit reporting suite, centered on the Qlik Warehouse.
   - Illustrative diagrams outlining entities, relationships, data flows, and integration points.
   - Reference model for Phase 2 build and ongoing scalability.
   - Delivered as formal architecture diagrams and an explanatory technical brief (Week 3).

6. **Data Infrastructure and Tooling Recommendations**
   - Comparative analysis of tooling and infrastructure options, including Qlik and alternatives.
   - Documentation of pros, cons, cost, and scalability considerations for each option.
   - Recommended approach for enhanced data management and dashboarding.
   - Delivered as an options assessment presentation and recommendations document (Week 3).

7. **Implementation Roadmap for Phase 2**
   - A phased roadmap outlining next steps, priorities, risk assessment, dependencies, and key milestones for the technical build.
   - Alignment with exit timelines and readiness criteria for go-live.
   - Clear delineation of owners, roles, and sequencing of Phase 2 workstreams.
   - Delivered as a visual timeline with supporting narrative (Week 4).

Each deliverable will be iteratively reviewed with VONQ's leadership and technical teams to ensure alignment with business goals and to incorporate feedback promptly. This structured approach guarantees transparency, accountability, and measurable value throughout the engagement lifecycle.
