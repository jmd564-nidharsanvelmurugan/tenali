# Overview

Pure Financial Advisors’ current reporting environment spans multiple internal teams, primarily data, technology, and marketing, all of which contribute to pipeline and customer acquisition reporting. The firm operates on a connected technology stack that includes Salesforce and Tamarac for client and portfolio data, Azure Blob Storage for data staging, and Microsoft Fabric and Azure Synapse as the core data platforms. Power BI serves as the primary reporting and analytics tool, supporting existing dashboards and performance views.  

Data sources currently integrated into the environment include Salesforce, Tamarac, Azure Blob Storage, and QuickBooks, with the latter identified for upcoming integration. The infrastructure is cloud‑based, leveraging Microsoft Fabric and Azure Synapse for data management and transformation. While manual processes are not specified, integration challenges exist around connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting.
