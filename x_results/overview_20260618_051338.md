# Overview

Pure Financial Advisors’ current reporting environment spans multiple internal teams, primarily data, technology, and marketing, all of which contribute to pipeline and customer acquisition reporting. The firm operates on a connected data ecosystem built around Salesforce and Tamarac for client and portfolio management, Azure Blob Storage for data hosting, and Microsoft Fabric and Azure Synapse as the core data platforms. Power BI serves as the primary reporting and analytics tool, supporting existing dashboards and performance views across these systems.

Data sources currently include Salesforce, Tamarac, Azure Blob Storage, and QuickBooks, with the latter identified for upcoming integration. While manual processes are not specified, the environment relies on batch data movement and structured reporting refreshes. Integration challenges center on connecting and ingesting data from QuickBooks and ensuring data quality for customer acquisition cost reporting. The infrastructure is fully cloud-based within Microsoft’s ecosystem, providing a foundation for scalable data management and analytics across Pure’s operational teams.
